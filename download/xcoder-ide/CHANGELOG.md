# Changelog

All notable changes to the XCoder IDE project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/),
and this project adheres to [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added
- Initial project structure with 11 Gradle modules
- Web editor mode with Ace Editor integration
- Native editor mode with Sora Editor
- Visual block-based editor (Sketchware-like)
- Terminal emulator with PTY support via NDK
- Git integration via JGit
- Build engine with Gradle wrapper support
- AI Copilot with multi-provider LLM support (OpenAI, Gemini, Claude)
- Plugin system with dynamic loading via DexClassLoader
- CI/CD pipelines via GitHub Actions
- Dark theme with Material 3 design system
- File manager with Storage Access Framework support
- Version Catalog (gradle/libs.versions.toml) for dependency management
